# Tic-Tac-Toe

A desktop Tic-Tac-Toe game built with Python and `pygame-ce`.

## Run on Windows

The project virtual environment is `.venv` inside this folder. To install the
dependencies again or set up a fresh copy:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Start the game:

```powershell
.\.venv\Scripts\python.exe main.py
```

## Play

- Choose **VS Computer** for an unbeatable computer opponent, or **2 Players**
  to play locally.
- Click an empty square to place your mark.
- **New Round** keeps the scoreboard; **Reset Score** clears it.
- Press **R** for a new round, **M** to switch modes, or **Esc** to quit.
